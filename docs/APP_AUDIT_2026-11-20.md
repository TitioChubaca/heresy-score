- Diagnostics: scripts/p2-diagnostics.js hardcodes release 0.15.5.
- Spotify integration: playlistTracks in runtime fitter and resume script use limit=100, while the current 2026 official Get Playlist Items reference says max 50 per page. Spotify 2026 renamed /tracks to /items; current usage is otherwise aligned. Respect dev-mode and playlist ownership limits. Audio Features/Analysis and preview access must NOT be assumed. - QA coverage: node mock tests for Spotify exist, but no package manifest, CI pipeline, or mobile E2E tests were found in the inspected known paths. Absence of a found workflow is a repository inspection finding, not an exhaustive Git tree enumeration.
