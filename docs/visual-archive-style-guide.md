# Visual Archive Style Guide

Heresy Score uses a spoiler-safe visual hierarchy for characters, voidcraft, worlds, theatres and locations.

## Provenance hierarchy

1. **Official Safe**
   - Official Games Workshop / Forge World / Black Library reference.
   - Must belong to the reader's current clearance or earlier.
   - Must not expose future form, allegiance, title, fate or setting changes.

2. **Canon Reference**
   - Diagram, miniature or other period-appropriate canonical reference.
   - Used when it communicates shape/layout better than promotional art.

3. **Visual Reconstruction**
   - Original reconstruction based only on information available through current reading clearance.
   - It is an imagination aid, not asserted as canonical appearance.
   - Must be visibly labelled `VISUAL RECONSTRUCTION`.

4. **REDACTED**
   - Used when no safe visual can be verified, when the visual itself is a spoiler, or when the record has not yet been curated.

## Reconstruction art direction

The archive should feel like a degraded Imperial pict-feed, not polished AI concept art.

### Preferred
- dark graphite / black-green base
- matte Death Guard / Administratum greens
- restrained aged brass accents
- low bloom
- harsh documentary exposure
- flat military scan lighting
- sensor noise, CRT scanlines and imperfect transmission
- partial silhouettes, long-distance orbital views and technical framing
- asymmetry and practical grime
- archival overlays added by the app where possible

### Avoid
- glossy cinematic bloom
- excessive green glow
- perfect symmetrical hero shots
- nebula-heavy fantasy backgrounds
- overly ornate decorative detail that competes with the subject
- fabricated factual specifications
- generated text inside the artwork whenever the app can render the labels itself

## Asset strategy

Prefer **image-only reconstructions** with minimal/no generated typography. The application should provide the reliable text layer:
- record name
- archive type
- clearance
- provenance badge
- notes
- canonical/reconstruction warning

This reduces generated-text artifacts and keeps all dossier cards visually coherent.

## Archive categories

### PERSONAE
Characters and identifiable individuals.

### VOIDCRAFT
Ships, stations, bottle-ships and other major spacecraft.

### WORLDS / THEATRES
Planets, moons, battle theatres and major geographic locations.

### SITES
Interior locations, facilities, fortifications and other recurring places.

## Spoiler protocol

The current reading clearance is the hard upper bound. A record can unlock only when:
- its name/identity is already known,
- the displayed description contains no future information,
- any visual shown is safe for that point in the reading.

When uncertain, use REDACTED.
